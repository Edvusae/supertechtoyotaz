## 🎯 The Vision
The design philosophy bridges the gap between **Industrial Brutalism** and **Premium Marketing**. We've stripped away the "visual noise" to focus on what matters: high-octane imagery, clear calls to action, and factory-standard performance.

## 🛠️ Performance Specs (Tech Stack)
*   **Architecture:** Modular BEM-lite CSS for scalable styling.
*   **Typography:** A triple-threat pairing of *Bebas Neue* (Impact), *Barlow Condensed* (Data), and *Barlow* (Readability).
*   **Logic:** Vanilla JS for scroll-aware navigation and high-performance interaction states.
*   **UX Strategy:** Marketing-first flow using the "F-Pattern" to drive user quotes and bookings.

## 🚀 Key Refactor Milestones

### 1. The Conversion Hero
The Hero section was rebuilt to move away from abstract CSS and toward **Visual Storytelling**.
*   **Fluid Typography:** Using `clamp()` for perfect legibility from 4K monitors down to an iPhone SE.
*   **Dynamic Glassmorphism:** A sticky navigation bar that adapts its density based on scroll depth.

### 2. Modern CSS Logic
We replaced heavy animation libraries with **Modern CSS Features**:
*   **`:has()` Selector:** Powering a custom cursor that reacts to interactive elements without JS overhead.
*   **CSS Variables (Tokens):** A centralized "Design Token" system in `:root` for instant brand-wide color or spacing pivots.
*   **Grid Layouts:** Using `auto-fit` and `minmax` to create a truly intrinsic layout that requires zero media queries for standard resizing.
